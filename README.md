\# Analytix AI

\### Your Personal AI Data Analyst



Analytix AI is an AI-powered data analytics application built with Python and Streamlit. It helps users analyze datasets, clean data, visualize trends, detect outliers, and generate intelligent insights through an interactive interface.



\## Features



\- 📊 Interactive Data Analysis

\- 🧹 Data Cleaning

\- 📈 Data Visualization

\- 🔍 Outlier Detection

\- 🤖 AI-Powered Insights

\- 🧠 Autonomous Data Analysis

\- 💬 Ask Your Data

\- 📑 Automated Reports

\- 💾 Saved Workspace

\- 📜 Analysis History

\- 📝 Activity Logs



\## Tech Stack



\- Python

\- Streamlit

\- Pandas

\- NumPy

\- Matplotlib

\- Seaborn

\- Plotly

\- Requests

\- ReportLab



\## Installation



Clone the repository:



```bash

git clone YOUR\_GITHUB\_REPOSITORY\_URL

```



Navigate to the project directory:



```bash

cd Analytix-AI

```



Create a virtual environment:



```bash

python -m venv .venv

```



Activate the virtual environment on Windows:



```bash

.venv\\Scripts\\activate

```



Install dependencies:



```bash

pip install -r requirements.txt

```



Run the application:



```bash

streamlit run app.py

```
